## 一、战略定位与差异化

### 1.1 目标市场（必须聚焦）

| 细分市场 | 优先级 | 目标用户 | 竞品 |
|----------|-------|---------|------|
| **NovaOS 生态 2D 游戏脚本层** | 🔴 首要 | RPi/Linux 掌机 2D 开发者 | LuaJIT |
| **微服务游戏逻辑语言** | 🔴 首要 | 分布式游戏服务器开发者 | Erlang/Elixir |
| **Kotlin 语法游戏脚本** | 🟡 次要 | Kotlin 开发者入门游戏 | GDScript, Lua |
| **嵌入式 Linux 掌机脚本** | 🟡 次要 | 掌机定制系统开发者 | Lua, Python |

### 1.2 放弃市场（明确不追求）

- ❌ **大型 3A 游戏引擎层**（C++/Rust 的地盘）
- ❌ **MCU/RTOS 嵌入式**（no_std 缺失，短期无解）
- ❌ **通用游戏语言替代**（无法取代 C#(Unity)/Rust(Godot)）
- ❌ **AAA 级渲染/物理**（ARC 隐藏成本无法接受）

### 1.3 差异化护城河

| 优势 | 现状 | 竞争者对比 |
|------|------|-----------|
| **Kotlin 语法** | ✅ 已就绪 | 独有，Lua/GDScript 无此优势 |
| **多模式执行**（AOT+JIT+字节码） | ✅ 已就绪 | 独有，比 LuaJIT 更灵活 |
| **零开销 FFI** | ✅ 已就绪 | 独有，直接 C ABI |
| **NovaOS 深度集成** | ⚠️ P12 跳过 | 独占生态 |
| **ARC 确定性内存** | ✅ 已就绪 | 优于 GC 语言 |

### 1.4 核心口号

> **"Kotlin 语法 × C 性能 × LuaJIT 生态替代者"**
> **"为 NovaOS 而生的游戏脚本语言"**

### 5.2 关键技术设计

#### 5.2.1 Lambda 捕获结构（Phase 1 核心）

```rust
// hir.rs 新增：捕获分析结果
pub struct ClosureInfo {
    pub params: Vec<HirParam>,
    pub body: HirBlock,
    pub captures: Vec<(String, HirType, CaptureKind)>,  // 捕获变量
}

pub enum CaptureKind {
    ByRef,   // 引用捕获（适合游戏热点）
    ByCopy,  // 拷贝捕获（小类型）
    ByMut,   // 可变捕获（游戏状态）
}
```

**捕获分析算法**（`hir.rs` 新增 `collect_captures`）：
1. 遍历 Lambda body，收集所有自由变量
2. 自由变量分类：可拷贝（`Int`/`Float`/`Bool`）→ `ByCopy`；可变访问 → `ByMut`；其他 → `ByRef`
3. 生成 `ClosureInfo`，传递给 MIR 层

#### 5.2.5 ask 真阻塞语义

```rust
// vm/actor.rs 重写 ask
pub fn ask(&mut self, id: ActorId, msg: Value, timeout: Option<Duration>) -> Value {
    self.send(id, msg);
    // 基于协程调度器轮询：
    // 1. 将当前协程挂起（yield）
    // 2. 让出调度
    // 3. 其他协程/Actor 处理消息
    // 4. 目标 Actor 将响应写入当前协程的 mailbox
    // 5. 当前协程恢复，返回响应
    // 6. 超时返回 Null
    self.scheduler.yield_current();
    self.receive_response_from(id, timeout)
}
```

#### 6.2.4 Channel 真阻塞

```rust
// channel.rs 重构
pub struct Channel {
    id: ChannelId,
    bound: usize,
    buffer: std::sync::Arc<std::sync::Mutex<VecDeque<Value>>>,
    send_cond: std::sync::Arc<tokio::sync::Notify>,  // 或 std::sync::Condvar
    recv_cond: std::sync::Arc<tokio::sync::Notify>,
}

impl Channel {
    pub fn send(&self, val: Value) {
        let mut buf = self.buffer.lock().unwrap();
        while self.bound > 0 && buf.len() >= self.bound {
            // 阻塞直到缓冲区有空间
            drop(buf);
            self.send_cond.notified().wait();
            buf = self.buffer.lock().unwrap();
        }
        buf.push_back(val);
        drop(buf);
        self.recv_cond.notify_one();
    }
    
    pub fn recv(&self) -> Value {
        loop {
            let mut buf = self.buffer.lock().unwrap();
            if let Some(val) = buf.pop_front() {
                drop(buf);
                self.send_cond.notify_one();
                return val;
            }
            drop(buf);
            // 阻塞直到缓冲区有值
            self.recv_cond.notified().wait();
        }
    }
}
```

```rust
// 新增 vm/allocator.rs
pub struct ArenaAllocator {
    base: *mut u8,
    capacity: usize,
    offset: usize,
}

impl ArenaAllocator {
    pub fn new(capacity: usize) -> Self {
        // 分配大块内存（一次 malloc）
        let layout = Layout::from_size_align_unchecked(capacity, 8);
        unsafe { std::alloc::alloc(layout) }
    }
    
    pub fn alloc(&mut self, size: usize, align: usize) -> Option<usize> {
        let aligned_offset = (self.offset + align - 1) & !(align - 1);
        if aligned_offset + size > self.capacity {
            return None;
        }
        let ptr = self.base.add(aligned_offset);
        self.offset = aligned_offset + size;
        Some(ptr as usize)
    }
    
    // 帧级 arena：每帧重置
    pub fn reset(&mut self) {
        self.offset = 0;
    }
}
```

```aura
// std.game.GameLoop
class GameLoop {
    var fps: Float = 60.0f
    var dt: Float = 0.016f
    var accumulator: Float = 0.0f
    var last_time: Float = 0.0f
    
    fun update(dt: Float) {}  // 虚方法：游戏更新
    fun render() {}           // 虚方法：游戏渲染
    fun handleInput(event: Event) {}  // 虚方法：输入处理
    
    fun run() {
        last_time = raylib.GetTime()
        while (raylib.WindowShouldClose() == false) {
            let current_time = raylib.GetTime()
            let frame_time = current_time - last_time
            last_time = current_time
            
            accumulator += frame_time
            while (accumulator >= dt) {
                update(dt)
                accumulator -= dt
            }
            
            raylib.BeginDrawing()
            render()
            raylib.EndDrawing()
            
            accumulator += frame_time * 0.01  // 防止螺旋
        }
    }
}

// 使用
class MyGame : GameLoop {
    override fun update(dt: Float) {
        player.update(dt)
        enemies.forEach { e -> e.update(dt) }
    }
    
    override fun render() {
        player.render()
        enemies.forEach { e -> e.render() }
    }
    
    override fun handleInput(event: Event) {
        when (event) {
            is Event.KeyPressed -> player.onKey(event.key)
            is Event.MouseClick -> player.onClick(event.x, event.y)
        }
    }
}

fun main() {
    val game = MyGame()
    game.run()
}
```

```aura
class StateMachine<T> {
    var current: T? = null
    var history: List<T> = mutableListOf()
    
    fun enter(state: T) {
        if (current != null) {
            history.add(current as T)
        }
        current = state
    }
    
    fun back() {
        if (history.isNotEmpty()) {
            current = history.removeAt(history.size - 1)
        }
    }
    
    fun currentState(): T {
        return current!!
    }
}

// 使用
```

```rust
pub fn mono_program(program: &mut HirProgram) {
    // 当前：identity<Int> 和 identity<String> 共享同一份 MIR（按 arity）

    let mut seen: HashMap<TypeSignature, String> = HashMap::new();

                seen.insert(sig, spec_name.clone());
                func.name = spec_name;
            }
        }
    }
}
```

### 9.2 关键技术设计

#### 9.2.1 内存压缩

```rust
// heap.rs 对象字段紧凑化
// 当前：HashMap<u16, Value> → ~1KB 起步
// 优化：Vec<(u16, Value)> → 8 bytes/entry + 数组开销

pub struct HeapObject {
    type_tag: u16,
    field_count: u16,
    fields: Vec<(u16, Value)>,  // 紧凑数组
}

impl HeapObject {
    pub fn get_field(&self, field: u16) -> Option<&Value> {
        self.fields.iter().find(|(f, _)| *f == field).map(|(_, v)| v)
    }
    
    pub fn set_field(&mut self, field: u16, value: Value) {
        if let Some((_, v)) = self.fields.iter_mut().find(|(f, _)| *f == field) {
            *v = value;
        } else {
            self.fields.push((field, value));
        }
    }
}
```

**内存优化效果**：
| 对象大小 | 当前（HashMap） | 优化后（Vec） | 节省 |
|---------|---------------|-------------|------|
| 3 字段 | ~1KB | ~56 bytes | ~94% |
| 10 字段 | ~1KB | ~136 bytes | ~86% |
| 100 字段 | ~4KB | ~856 bytes | ~78% |

## 十二、放弃清单

> 明确不追求的目标，避免资源浪费。

### 12.1 技术放弃

- ❌ **通用游戏引擎语言**（C++/Rust 的地盘）
- ❌ **3A 级游戏支持**（ARC 隐藏成本无法接受）
- ❌ **MCU/RTOS 嵌入式**（no_std 缺失，短期无解）
- ❌ **无 GC 暂停保证**（ARC 有 3-5% 开销）
- ❌ **借用检查 / 所有权**（Rust 风格太复杂）
- ❌ **unsafe 逃逸**（FFI 已是唯一 unsafe）
- ❌ **进程内 PassManager**（委托 llc `-O`）
- ❌ **inkwell 绑定**（文本 IR 已足够）

### 12.2 市场放弃

- ❌ **通用游戏语言替代**（无法取代 C#/Rust）
- ❌ **大型 3D 游戏**（3A 级）
- ❌ **掌机系统级语言**（系统用 C/Rust，Aura 只做脚本层）
- ❌ **跨平台游戏引擎**（不做引擎，只做脚本）

### 12.3 团队放弃

- ❌ **单人全栈**（部分工作外包）
- ❌ **完美主义**（够用即可，不追求 100%）
- ❌ **同时开发多个方向**（聚焦 NovaOS 2D）

## 结语

> **Aura 在游戏领域的成功，不靠"全能"，靠"聚焦"。**
