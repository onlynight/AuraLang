# Aura 编译器后端：LLVM 集成完整技术方案

---

## 一、方案概述

### 1.1 设计目标

将 LLVM 作为 Aura 编译器的后端，实现：
- **跨平台编译**：Windows 开发机 → ARM Linux（树莓派）等目标平台
- **C 级性能**：利用 LLVM 的极致优化 pipeline
- **开发体验**：Aura 开发者无需关心底层 LLVM 细节
- **可维护性**：通过 LLVM IR 作为中间层，解耦前端与后端

### 1.2 整体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                      Aura 编译器前端                            │
│  ┌─────────────────────────────────────────────────────────┐    │
```

## 二、技术选型

### 2.1 LLVM 绑定方案

Aura 编译器使用 Rust 实现，与 LLVM 的交互有以下方案：

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **inkwell** | 类型安全、Rust 惯用 API、活跃维护 | 包装层有一定开销 | ⭐⭐⭐⭐⭐ |
| **llvm-sys** | 直接调用 C API、完全控制 | 不安全、需手动管理内存 | ⭐⭐⭐ |
| **调用 clang CLI** | 无需绑定、简单 | 进程开销大、无法精细控制 | ⭐⭐ |

**推荐：inkwell**，它提供了对 LLVM C API 的安全 Rust 封装，同时保持高性能。

```toml
[dependencies]
inkwell = { git = "https://github.com/TheDan64/inkwell" }
# 或使用 crates.io
inkwell = "0.5.0"
```

### 2.2 LLVM 版本策略

```rust
// 支持多个 LLVM 版本，通过 feature 切换
#[cfg(feature = "llvm18")]
use inkwell::LLVM_VERSION_18;

#[cfg(feature = "llvm17")]
use inkwell::LLVM_VERSION_17;

#[cfg(feature = "llvm16")]
use inkwell::LLVM_VERSION_16;
```

**建议**：默认使用 LLVM 17+，在 CI 中同时测试多个版本。

## 三、LLVM IR 生成器核心模块设计

### 3.1 模块结构

```rust
// aura-compiler/src/codegen/llvm.rs

mod context;
mod types;
mod builder;
mod ffi;
mod optimizer;
mod target;

use inkwell::context::Context;
use inkwell::module::Module;
use inkwell::targets::{Target, TargetMachine};
use inkwell::OptimizationLevel;

/// LLVM 代码生成器
pub struct LlvmCodeGenerator {
    context: Context,
    module: Module,
    builder: Builder,
    type_mapper: TypeMapper,
    function_mapper: FunctionMapper,
    target_machine: TargetMachine,
}

impl LlvmCodeGenerator {
    /// 从 Aura AST 生成 LLVM IR
    pub fn generate(&mut self, ast: &AuraAst) -> Result<Module, CodegenError> {
        // 1. 初始化 LLVM
        self.initialize()?;
        
        // 2. 生成模块元数据
        self.generate_module_metadata(ast)?;
        
        // 3. 生成全局变量
        self.generate_globals(ast)?;
        
        // 4. 生成函数
        for func in &ast.functions {
            self.generate_function(func)?;
        }
        
        // 5. 生成 FFI 声明
        self.generate_ffi_declarations(ast)?;
        
        // 6. 优化
        self.optimize()?;
        
        // 7. 输出目标代码
        self.generate_object()?;
        
        Ok(self.module.clone())
    }
}
```

### 3.2 类型映射 (Aura Type → LLVM Type)

这是最基础也是最关键的一步，需要精确映射每种 Aura 类型到 LLVM 类型：

```rust
use inkwell::types::{BasicType, BasicTypeEnum};

pub struct TypeMapper<'ctx> {
    context: &'ctx Context,
}

impl<'ctx> TypeMapper<'ctx> {
    pub fn map(&self, aura_type: &AuraType) -> BasicTypeEnum<'ctx> {
        match aura_type {
            // 基本类型
            AuraType::Int => self.context.i32_type().as_basic_type_enum(),
            AuraType::Long => self.context.i64_type().as_basic_type_enum(),
            AuraType::Short => self.context.i16_type().as_basic_type_enum(),
            AuraType::Byte => self.context.i8_type().as_basic_type_enum(),
            AuraType::Float => self.context.f32_type().as_basic_type_enum(),
            AuraType::Double => self.context.f64_type().as_basic_type_enum(),
            AuraType::Boolean => self.context.bool_type().as_basic_type_enum(),
            AuraType::Char => self.context.i16_type().as_basic_type_enum(),
            
            // 字符串 (编译为 *mut i8 或自定义结构)
            AuraType::String => {
                // 方案1: 直接映射为 C 字符串指针
                self.context.i8_type().ptr_type(AddressSpace::default()).as_basic_type_enum()
                
                // 方案2: 自定义字符串结构体 (更高级)
                // struct AuraString { ptr: *mut u8, len: usize, cap: usize }
            }
            
            // 结构体 (struct)
            AuraType::Struct(fields) => {
                let llvm_fields: Vec<BasicTypeEnum> = fields
                    .iter()
                    .map(|f| self.map(&f.ty))
                    .collect();
                self.context.struct_type(&llvm_fields, false).as_basic_type_enum()
            }
            
            // 枚举 (tagged union)
            AuraType::Enum(variants) => {
                // 编译为 [tag: i32, union: ...]
                self.map_enum(variants)
            }
            
            // 指针类型
            AuraType::Pointer(inner) => {
                let inner_ty = self.map(inner);
                inner_ty.ptr_type(AddressSpace::default()).as_basic_type_enum()
            }
            
            // 泛型 (单态化后具体类型)
            AuraType::Generic(name, args) => {
                self.map_generic(name, args)
            }
            
            // 函数类型
            AuraType::Function(params, return_type) => {
                let param_types: Vec<BasicTypeEnum> = params
                    .iter()
                    .map(|p| self.map(p))
                    .collect();
                let return_ty = self.map(return_type);
                return_ty.fn_type(&param_types, false).ptr_type(AddressSpace::default()).as_basic_type_enum()
            }
        }
    }
}
```

### 3.3 函数生成

```rust
pub struct FunctionGenerator<'ctx, 'a> {
    context: &'ctx Context,
    module: &'a Module<'ctx>,
    builder: &'a mut Builder<'ctx>,
    type_mapper: &'a TypeMapper<'ctx>,
    scope: Scope<'ctx>,
}

impl<'ctx, 'a> FunctionGenerator<'ctx, 'a> {
    pub fn generate(&mut self, func: &AuraFunction) -> Result<(), CodegenError> {
        // 1. 获取或创建 LLVM 函数
        let llvm_func = self.get_or_create_function(func)?;
        
        // 2. 创建基本块
        let entry_block = self.context.append_basic_block(llvm_func, "entry");
        self.builder.position_at_end(entry_block);
        
        // 3. 处理参数
        self.handle_parameters(func, llvm_func)?;
        
        // 4. 生成函数体
        self.generate_body(&func.body)?;
        
        // 5. 生成返回值
        self.generate_return(&func.return_type, &func.body)?;
        
        Ok(())
    }
    
    fn generate_statement(&mut self, stmt: &AuraStatement) -> Result<Value, CodegenError> {
        match stmt {
            AuraStatement::VariableDeclaration(name, ty, expr) => {
                // 分配栈变量
                let llvm_ty = self.type_mapper.map(ty);
                let alloca = self.builder.build_alloca(llvm_ty, name);
                
                // 生成初始值
                if let Some(expr) = expr {
                    let value = self.generate_expression(expr)?;
                    self.builder.build_store(alloca, value);
                }
                
                // 存入作用域
                self.scope.declare(name, alloca);
                
                Ok(alloca.into())
            }
            
            AuraStatement::Assignment(target, value) => {
                let llvm_value = self.generate_expression(value)?;
                let target_ptr = self.scope.lookup(target)?;
                self.builder.build_store(target_ptr, llvm_value);
                Ok(llvm_value)
            }
            
            AuraStatement::If(condition, then_block, else_block) => {
                self.generate_if(condition, then_block, else_block)
            }
            
            AuraStatement::Loop(condition, body) => {
                self.generate_loop(condition, body)
            }
            
            AuraStatement::Return(expr) => {
                let llvm_value = self.generate_expression(expr)?;
                self.builder.build_return(Some(&llvm_value));
                Ok(llvm_value)
            }
        }
    }
}
```

### 3.4 控制流生成

```rust
impl<'ctx, 'a> FunctionGenerator<'ctx, 'a> {
    fn generate_if(
        &mut self,
        condition: &AuraExpression,
        then_block: &AuraBlock,
        else_block: &Option<AuraBlock>,
    ) -> Result<Value, CodegenError> {
        let current_func = self.builder.get_insert_block().unwrap().get_parent().unwrap();
        
        // 创建基本块
        let then_bb = self.context.append_basic_block(current_func, "then");
        let else_bb = self.context.append_basic_block(current_func, "else");
        let merge_bb = self.context.append_basic_block(current_func, "merge");
        
        // 生成条件表达式
        let cond_value = self.generate_expression(condition)?;
        
        // 创建分支
        self.builder.build_conditional_branch(
            cond_value.into_int_value(),
            then_bb,
            else_bb,
        );
        
        // 生成 then 块
        self.builder.position_at_end(then_bb);
        self.generate_block(then_block)?;
        self.builder.build_unconditional_branch(merge_bb);
        
        // 生成 else 块
        if let Some(else_block) = else_block {
            self.builder.position_at_end(else_bb);
            self.generate_block(else_block)?;
        } else {
            self.builder.position_at_end(else_bb);
            self.builder.build_unconditional_branch(merge_bb);
        }
        
        // 设置当前块为 merge
        self.builder.position_at_end(merge_bb);
        
        Ok(self.builder.build_phi(...)?) // 如果有返回值
    }
    
    fn generate_loop(
        &mut self,
        condition: &AuraExpression,
        body: &AuraBlock,
    ) -> Result<Value, CodegenError> {
        let current_func = self.builder.get_insert_block().unwrap().get_parent().unwrap();
        
        let cond_bb = self.context.append_basic_block(current_func, "loop_cond");
        let body_bb = self.context.append_basic_block(current_func, "loop_body");
        let end_bb = self.context.append_basic_block(current_func, "loop_end");
        
        // 跳到条件块
        self.builder.build_unconditional_branch(cond_bb);
        
        // 条件块
        self.builder.position_at_end(cond_bb);
        let cond_value = self.generate_expression(condition)?;
        self.builder.build_conditional_branch(
            cond_value.into_int_value(),
            body_bb,
            end_bb,
        );
        
        // 循环体
        self.builder.position_at_end(body_bb);
        self.generate_block(body)?;
        self.builder.build_unconditional_branch(cond_bb);
        
        // 结束
        self.builder.position_at_end(end_bb);
        
        Ok(self.context.i32_type().const_int(0, false).as_basic_value_enum())
    }
}
```

## 四、FFI 处理

### 4.1 外部函数声明

```rust
impl<'ctx, 'a> FfiGenerator<'ctx, 'a> {
    pub fn generate_ffi_declarations(
        &mut self,
        ffi_decls: &[FfiDeclaration],
    ) -> Result<(), CodegenError> {
        for decl in ffi_decls {
            match decl {
                FfiDeclaration::Library { name, functions } => {
                    // 生成 extern "C" 函数声明
                    for func in functions {
                        self.generate_extern_function(name, func)?;
                    }
                }
                FfiDeclaration::Constant { name, ty, value } => {
                    // 生成全局常量
                    self.generate_extern_constant(name, ty, value)?;
                }
            }
        }
        Ok(())
    }
    
    fn generate_extern_function(
        &mut self,
        lib_name: &str,
        func: &AuraFunction,
    ) -> Result<(), CodegenError> {
        let llvm_return_ty = self.type_mapper.map(&func.return_type);
        let llvm_param_tys: Vec<BasicTypeEnum> = func.parameters
            .iter()
            .map(|p| self.type_mapper.map(&p.ty))
            .collect();
        
        // 声明函数类型
        let fn_type = llvm_return_ty.fn_type(&llvm_param_tys, false);
        
        // 创建外部函数声明
        let llvm_func = self.module.add_function(
            func.name.as_str(),
            fn_type,
            Some(Linkage::External),
        );
        
        // 设置 C 调用约定
        llvm_func.set_call_conv(CallingConvention::C);
        
        // 添加别名（可选，用于动态库加载）
        let alias_name = format!("{}_{}", lib_name, func.name);
        llvm_func.set_alias_name(&alias_name);
        
        Ok(())
    }
}
```

### 4.2 FFI 调用生成

```rust
impl<'ctx, 'a> FunctionGenerator<'ctx, 'a> {
    fn generate_ffi_call(
        &mut self,
        func_name: &str,
        args: &[AuraExpression],
    ) -> Result<Value, CodegenError> {
        // 查找外部函数
        let llvm_func = self.module.get_function(func_name)
            .ok_or(CodegenError::UndefinedFunction(func_name.to_string()))?;
        
        // 生成参数
        let mut llvm_args = Vec::new();
        for arg in args {
            let arg_value = self.generate_expression(arg)?;
            llvm_args.push(arg_value);
        }
        
        // 生成调用
        let call = self.builder.build_call(
            llvm_func,
            &llvm_args,
            format!("ffi_call_{}", func_name).as_str(),
        );
        
        // 设置调用约定为 C
        call.set_calling_convention(CallingConvention::C);
        
        // 获取返回值
        Ok(call.try_as_basic_value().left().unwrap_or(
            self.context.i32_type().const_int(0, false).as_basic_value_enum()
        ))
    }
}
```

### 5.1 优化级别配置

```rust
pub enum OptimizationLevel {
    /// 无优化，最快编译速度 (O0)
    None,
    /// 平衡优化 (O1)
    Balanced,
    /// 激进优化 (O2)
    Aggressive,
    /// 极致优化 (O3)
    Extreme,
    /// 体积优化 (Os)
    Size,
    /// 极致体积优化 (Oz)
    SizeExtreme,
}

impl OptimizationLevel {
    pub fn to_llvm_level(&self) -> llvm::OptimizationLevel {
        match self {
            OptimizationLevel::None => llvm::OptimizationLevel::None,
            OptimizationLevel::Balanced => llvm::OptimizationLevel::Less,
            OptimizationLevel::Aggressive => llvm::OptimizationLevel::Default,
            OptimizationLevel::Extreme => llvm::OptimizationLevel::Aggressive,
            OptimizationLevel::Size => llvm::OptimizationLevel::Default, // + size opts
            OptimizationLevel::SizeExtreme => llvm::OptimizationLevel::Default, // + size opts
        }
    }
}
```

### 5.2 优化 Pass 管理

```rust
pub struct Optimizer<'ctx, 'a> {
    context: &'ctx Context,
    module: &'a mut Module<'ctx>,
    pass_manager: PassManager<'ctx, 'a>,
}

impl<'ctx, 'a> Optimizer<'ctx, 'a> {
    pub fn new(context: &'ctx Context, module: &'a mut Module<'ctx>) -> Self {
        let pass_manager = PassManager::new(module);
        Self {
            context,
            module,
            pass_manager,
        }
    }
    
    pub fn optimize(&mut self, level: OptimizationLevel) -> Result<(), CodegenError> {
        // 1. 添加标准优化 Pass
        self.add_standard_passes(level)?;
        
        // 2. 添加 Aura 特定优化 Pass
        self.add_aura_specific_passes(level)?;
        
        // 3. 运行优化
        self.pass_manager.run_on(&self.module)?;
        
        // 4. 验证 IR
        if let Err(e) = self.module.verify(true) {
            return Err(CodegenError::VerificationFailed(e));
        }
        
        Ok(())
    }
    
    fn add_standard_passes(&mut self, level: OptimizationLevel) -> Result<(), CodegenError> {
        match level {
            OptimizationLevel::None => {
                // 只添加验证 Pass
                self.pass_manager.add_pass("verify");
            }
            OptimizationLevel::Balanced => {
                // O1: 基础优化
                self.pass_manager.add_pass("early-cse");
                self.pass_manager.add_pass("simplify-cfg");
                self.pass_manager.add_pass("reassociate");
                self.pass_manager.add_pass("licm");  // 循环不变代码外提

                // O2: 标准优化
```

## 六、目标代码生成

### 6.1 目标平台配置

```rust
#[derive(Debug, Clone)]
pub struct TargetTriple {
    pub arch: Architecture,
    pub vendor: Vendor,
    pub os: OperatingSystem,
    pub abi: Abi,
}

impl TargetTriple {
    pub fn from_string(s: &str) -> Result<Self, CodegenError> {
        // 解析目标三元组
        // e.g., "aarch64-unknown-linux-gnu"
        let parts: Vec<&str> = s.split('-').collect();
        if parts.len() < 3 {
            return Err(CodegenError::InvalidTarget(s.to_string()));
        }
        
        let arch = Architecture::from_str(parts[0])?;
        let vendor = Vendor::from_str(parts[1])?;
        let os = OperatingSystem::from_str(parts[2])?;
        let abi = if parts.len() > 3 {
            Abi::from_str(parts[3])?
        } else {
            Abi::Unknown
        };
        
        Ok(TargetTriple { arch, vendor, os, abi })
    }
    
    pub fn to_llvm_triple(&self) -> String {
        format!("{}-{}-{}", self.arch, self.vendor, self.os)
    }
}

// 预定义目标平台
impl TargetTriple {
    pub fn windows_x86_64() -> Self {
        Self {
            arch: Architecture::X86_64,
            vendor: Vendor::Pc,
            os: OperatingSystem::Windows,
            abi: Abi::Msvc,
        }
    }
    
    pub fn linux_arm64() -> Self {
        Self {
            arch: Architecture::Aarch64,
            vendor: Vendor::Unknown,
            os: OperatingSystem::Linux,
            abi: Abi::Gnu,
        }
    }
    
    pub fn linux_arm32() -> Self {
        Self {
            arch: Architecture::Armv7,
            vendor: Vendor::Unknown,
            os: OperatingSystem::Linux,
            abi: Abi::Gnueabihf,
        }
    }
}
```

```rust
pub struct ObjectGenerator {

impl ObjectGenerator {
    pub fn new(target_triple: &TargetTriple, level: OptimizationLevel) -> Result<Self, CodegenError> {
        // 初始化 LLVM 目标
        Target::initialize_all(&InitializationConfig::default());
        
        let triple_str = target_triple.to_llvm_triple();

            &triple_str,

            "",         // 特性
            level.to_llvm_level(),
            RelocMode::Pic,
            CodeModel::Default,
        ).map_err(|e| CodegenError::TargetMachineCreation(e.to_string()))?;
        
        Ok(Self {
            target_machine,
            output_format: OutputFormat::Executable,
        })
    }
    
    pub fn generate_object(
        &self,
        module: &Module,
        output_path: &Path,
    ) -> Result<(), CodegenError> {
        // 1. 生成目标文件 (.o)
        let object_bytes = self.target_machine.write_to_memory_buffer(module, FileType::Object)
            .map_err(|e| CodegenError::CodeGenerationFailed(e.to_string()))?;
        
        // 2. 写入目标文件
        std::fs::write(output_path, object_bytes.as_slice())?;
        
        // 3. 调用系统链接器（可选）
        if self.output_format == OutputFormat::Executable {
            self.link_object(output_path)?;
        }
        
        Ok(())
    }
    
    fn link_object(&self, object_path: &Path) -> Result<(), CodegenError> {
        // 调用链接器
        let output_path = object_path.with_extension("");
        let linker = self.get_linker()?;
        
        let status = std::process::Command::new(linker)
            .arg(object_path)
            .arg("-o")
            .arg(&output_path)
            .status()
            .map_err(|e| CodegenError::LinkerFailed(e.to_string()))?;
        
        if !status.success() {
            return Err(CodegenError::LinkerFailed("Linker returned non-zero status".to_string()));
        }
        
        Ok(())
    }
    
    fn get_linker(&self) -> Result<String, CodegenError> {
        // 根据目标平台选择合适的链接器
        #[cfg(target_os = "windows")]
        {
            // 使用 lld 或 MSVC link.exe
            Ok("lld".to_string())
        }
        
        #[cfg(target_os = "linux")]
        {
            // 使用 GNU ld 或 lld
            Ok("ld".to_string())
        }
    }
}
```

```rust
// 生成 LLVM IR 时，注入 runtime 库的链接信息
impl<'ctx, 'a> ModuleGenerator<'ctx, 'a> {
    fn link_runtime(&mut self, runtime_lib: &str) -> Result<(), CodegenError> {
        // 添加 runtime 库的声明
        let runtime_functions = [
            ("aura_arc_increment", "void", &["*mut c_void"]),
            ("aura_arc_decrement", "void", &["*mut c_void"]),
            ("aura_coroutine_yield", "void", &["*mut c_void"]),
        ];
        
        for (name, ret, params) in runtime_functions {
            let llvm_ret_ty = self.type_mapper.map_type(ret);
            let llvm_param_tys: Vec<BasicTypeEnum> = params
                .iter()
                .map(|p| self.type_mapper.map_type(p))
                .collect();
            
            let fn_type = llvm_ret_ty.fn_type(&llvm_param_tys, false);
            self.module.add_function(name, fn_type, Some(Linkage::External));
        }
        
        // 设置链接选项
        self.module.set_debug_info(true);
        self.module.set_module_flag("runtime_lib", runtime_lib);
        
        Ok(())
    }
```

### 8.3 完整编译流程

```rust
// aura-compiler/src/main.rs
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let args = Args::parse();
    
    // 1. 解析源代码
    let ast = Parser::parse(&args.input)?;
    
    // 2. 语义分析
    let analyzed_ast = SemanticAnalyzer::analyze(ast)?;
    
    // 3. 生成 LLVM IR
    let mut codegen = LlvmCodeGenerator::new(
        &args.target_triple,
        args.optimization_level,
    )?;
    let module = codegen.generate(&analyzed_ast)?;
    
    // 4. 优化
    codegen.optimize(module)?;
    
    // 5. 生成目标代码
    codegen.generate_object(&args.output)?;
    
    // 6. 链接（如果需要可执行文件）
    if args.output_type == OutputType::Executable {
        codegen.link_executable(&args.output)?;
    }
    
    Ok(())
}
```
