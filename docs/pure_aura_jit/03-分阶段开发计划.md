# 03 · 分阶段开发计划

> **范围**：S0–S5 六个阶段，每阶段独立可开发、独立可验收、独立可回退
> **配套文档**：[02-技术方案.md](./02-技术方案.md)（设计）、[04-测试与验收矩阵.md](./04-测试与验收矩阵.md)（测试）、[05-风险与开放问题.md](./05-风险与开放问题.md)（风险）
> **总工期估算**：8–14 周（单人全职），与 `docs/pure_aura/` 宏观路线并行

---

## 一、阶段总览

```text
S0 ──→ S1 ──→ S2 ──→ S3 ──→ S4 ──→ S5
│      │      │      │      │      │
基础   单测   Clif   FFI    派发   性能
契约   覆盖   联调   边界   接线   基准
2 周   1 周   2 周   2 周   2 周   3 周
```

**关键原则**：

1. **每个阶段可独立验收**——每阶段有明确的「完成判定」标准，不依赖后续阶段
2. **每个阶段可独立回退**——每阶段失败只需放弃本阶段，不影响已交付的阶段
3. **前置阶段是后置阶段的前提**——S1 依赖 S0，S2 依赖 S1，以此类推
4. **纯 Aura 侧与 Rust 侧并行开发**——S1/S2 是纯 Aura 侧，S3 是 Rust 侧，S4 是接线，S5 是基准

#### S2.5 Clif IR 格式规范

`JitLower.aura` 输出的 .clif 格式需符合 Cranelift 0.116 规范：

```text
; 函数定义
function %<name>(i64, i64, i64, i64) {
    block0:
        ; 指令序列
        v0 = iconst.i64 42
        v1 = load.i64 local_payload[0]
        v2 = iadd v1, v1
        store.i64 v2, out_payload
        return

    ; 可选：额外基本块（条件跳转）
    block1:
        ...
}
```

**关键格式点**：

| 格式点 | 要求 | 当前状态 |
|--------|------|---------|
| 函数签名 | `function %<name>(i64, i64, i64, i64)` | ✅ 已实现 |
| 基本块 | `block<N>:` 格式 | ✅ 已实现 |
| SSA 值名 | `v<N>` 格式 | ✅ 已实现 |
| 常量指令 | `iconst.i64 <N>` | ✅ 已实现 |
| 局部变量加载 | `load.i64 local_payload[<N>]` | ✅ 已实现 |
| 算术指令 | `iadd/isub/imul/sdiv/srem/ineg` | ✅ 已实现 |
| 比较指令 | `icmp.<op> v<N>, v<N>` | ✅ 已实现 |
| 条件跳转 | `br_if <op> v<N>, <block>` | ⚠️ 需验证 |
| 无条件跳转 | `br <block>` | ⚠️ 需验证 |
| 函数调用 | `call <func_ref>` | ⚠️ 需验证 |
| 返回 | `return` 或 `return v<N>` | ⚠️ 需验证 |

#### S2.6 Rust 侧验证工具

`compiler/examples/jit_clif_verify.rs`：

```rust
//! Clif IR 格式验证工具
//!
//! 读取 .clif 文本文件，调用 Cranelift 编译，验证格式正确性。
//! 用法：cargo run --features jit --example jit_clif_verify -- <path>.clif

use cranelift::prelude::*;
use cranelift_jit::{JITBuilder, JITModule};
use cranelift_module::{Linkage, Module};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let path = std::env::args().nth(1).expect("用法: jit_clif_verify <path>.clif");
    let clif_text = std::fs::read_to_string(&path)?;
    
    println!("验证文件: {}", path);
    println!("内容:\n{}", clif_text);
    
    // 调用 Cranelift 编译
    let flags = cranelift::settings::builder();
    let builder = JITBuilder::with_flags(flags, cranelift_module::default_libcall_names())?;
    let mut module = JITModule::new(builder);
    
    // 使用 Cranelift 的文本 IR 解析器
    let (module, func_id) = module.compile(&clif_text)?;
    
    let code = module.finalized_code(func_id).ok_or("编译失败")?;
    println!("✓ 编译成功，机器码大小: {} 字节", code.len());
    
    Ok(())
}
```

```rust
//! JIT FFI 边界（纯 Aura 侧 → Cranelift + mmap）
//!
//! 三个 FFI 函数：
//! - jit_compile: .clif 文本 → 机器码 blob（base64）
//! - jit_load:    base64 blob → entry_token（mmap R^X）
//! - jit_call:    entry_token + args → 返回值

use std::collections::HashMap;
use std::sync::Mutex;

use cranelift_jit::{JITBuilder, JITModule};
use cranelift_module::{Linkage, Module};

/// 已装载的机器码表：entry_token → (code_ptr, code_len, dispatch_table)
static LOADED_MODULES: Mutex<HashMap<String, (usize, usize, usize)>> = Mutex::new(HashMap::new());

/// 全局 JITBuilder（复用）
static mut JIT_BUILDER: Option<JITBuilder> = None;

fn get_jit_builder() -> &'static JITBuilder {
    unsafe {
        if JIT_BUILDER.is_none() {
            let flags = cranelift::settings::builder();
            let builder = JITBuilder::with_flags(flags, cranelift_module::default_libcall_names()).unwrap();
            JIT_BUILDER = Some(builder);
        }
        JIT_BUILDER.as_ref().unwrap()
    }
}

/// @native fun jit_compile(clif_text: String) -> String
///
/// 输入：Cranelift 文本 IR（.clif）
/// 输出：base64 编码的机器码 blob（失败返回空串）
#[export_name = "aura_jit_compile"]
pub extern "C" fn jit_compile(clif_text: *const c_char) -> *mut c_char {
    let clif = unsafe { CStr::from_ptr(clif_text) }.to_str().unwrap_or("");
    
    if clif.is_empty() {
        return to_c_string("");
    }
    
    // 调用 Cranelift 编译
    match compile_clif(clif) {
        Ok(blob) => {
            let b64 = base64::encode(&blob);
            to_c_string(&b64)
        }
        Err(e) => {
            eprintln!("[jit_compile] 编译失败: {}", e);
            to_c_string("")
        }
    }
}

/// @native fun jit_load(blob_b64: String) -> String
///
/// 输入：base64 编码的机器码 blob
/// 输出：entry_token（失败返回空串）
#[export_name = "aura_jit_load"]
pub extern "C" fn jit_load(blob_b64: *const c_char) -> *mut c_char {
    let b64 = unsafe { CStr::from_ptr(blob_b64) }.to_str().unwrap_or("");
    
    if b64.is_empty() {
        return to_c_string("");
    }
    
    // base64 解码
    let blob = match base64::decode(b64) {
        Ok(data) => data,
        Err(e) => {
            eprintln!("[jit_load] base64 解码失败: {}", e);
            return to_c_string("");
        }
    };
    
    // mmap(RW) → copy → mprotect(RX)
    match mmap_and_protect(&blob) {
        Ok((addr, len)) => {
            let token = format!("fn@{:x}", addr);
            LOADED_MODULES.lock().unwrap().insert(token.clone(), (addr, len, 0));
            to_c_string(&token)
        }
        Err(e) => {
            eprintln!("[jit_load] mmap 失败: {}", e);
            to_c_string("")
        }
    }
}

/// @native fun jit_call(entry_token: String, args: String, out_slot: Int) -> String
///
/// 输入：entry_token + args（记录表）+ out_slot
/// 输出：返回值（tag|payload）或 "DEOPT" 或空串
#[export_name = "aura_jit_call"]
pub extern "C" fn jit_call(
    entry_token: *const c_char,
    args: *const c_char,
    out_slot: i64,
) -> *mut c_char {
    let token = unsafe { CStr::from_ptr(entry_token) }.to_str().unwrap_or("");
    let args_str = unsafe { CStr::from_ptr(args) }.to_str().unwrap_or("");
    
    // 查找已装载的模块
    let modules = LOADED_MODULES.lock().unwrap();
    let (addr, _len, _dispatch) = match modules.get(token) {
        Some(m) => *m,
        None => return to_c_string(""),
    };
    
    // 反序列化 args
    let jit_args = parse_jit_args(args_str);
    
    // 调用机器码入口
    let result = unsafe {
        let entry: extern "C" fn(*const JitValue, *mut JitValue, usize, *const ()) = 
            std::mem::transmute(addr);
        let mut out = JitValue::null();
        entry(jit_args.as_ptr(), &mut out, jit_args.len(), std::ptr::null());
        out
    };
    
    // 序列化返回值
    to_c_string(&format!("{}|{}", result.tag, result.payload))
}
```

```aura
// VM 与 JIT 的桥接层
package aura.lang.compiler.vm

import aura.lang.compiler.jit.*

/// VM JIT 桥接：在 VM 调用函数时检查是否需要 JIT 编译
class VmJitBridge {
    
    var jitState: JitState = JitState()
    var enabled: Boolean = false
    
    init() {
        this.jitState = JitState()
        this.enabled = false
    }
    
    fun enable(): Unit {
        this.enabled = true
    }
    
    /// VM 调用函数前检查：是否需要 JIT 编译
    fun checkCall(funcIdx: Int, funcName: String, code: String, funcs: String) -> String {
        if (!this.enabled) {
            return "defer"
        }
        
        // 检查是否已编译
        if (this.jitState.isCompiled(funcIdx)) {
            return "native"
        }
        
        // 检查是否已跳过
        if (this.jitState.isSkipped(funcIdx)) {
            return "skip"
        }
        
        // 累加调用计数
        val count: Int = this.jitState.incCallCount(funcIdx)
        
        // Fix A：入口函数强制编译
        // Fix B：检查是否达阈值
        if (this.jitState.reachThreshold(funcIdx) || isEntryPoint(funcName)) {
            // 尝试 JIT 编译
            return tryJitCompile(funcIdx, code, funcs)
        }
        
        return "defer"
    }
    
    /// 尝试 JIT 编译
    private fun tryJitCompile(funcIdx: Int, code: String, funcs: String) -> String {
        // 1. 检查白名单
        val skipReason: String = jitSkipReason(code)
        if (skipReason != "") {
            this.jitState.skip(funcIdx, skipReason)
            return "skip"
        }
        
        // 2. 规划编译顺序（Fix B：被调用者先）
        val order: String = jitCompileOrder(funcs, funcIdx)
        val orderLines: Int = jitLineCount(order)
        var i: Int = 0
        
        while (i < orderLines) {
            val curIdx: Int = jitParseInt(jitLineAt(order, i))
            val curCode: String = jitFuncCode(funcs, curIdx, code)
            
            // 3. 预解码
            val predecodeResult: JitLinkResult = jitPredecode(curIdx, curCode)
            if (predecodeResult.decodeFailed) {
                this.jitState.skip(curIdx, "预解码失败")
                return "skip"
            }
            
            // 4. 优化
            val optResult: JitOptResult = jitOptimize(predecodeResult.code, ...)
            
            // 5. 发射 Clif IR
            val clifText: String = jitLowerToClif(optResult.code, ...)
            
            // 6. FFI：编译
            val blob: String = @native jit_compile(clifText)
            if (blob == "") {
                this.jitState.skip(curIdx, "Cranelift 编译失败")
                return "skip"
            }
            
            // 7. FFI：装载
            val entryToken: String = @native jit_load(blob)
            if (entryToken == "") {
                this.jitState.skip(curIdx, "mmap 装载失败")
                return "skip"
            }
            
            // 8. 记录编译成功
            this.jitState.insert(curIdx)
            
            i = i + 1
        }
        
        return "native"
    }
}
```
