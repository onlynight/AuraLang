### 各关键字修复状态

| 关键字 | 状态 | 实现说明 |
|--------|------|----------|
| `open` | ✅ | 类修饰符 + 函数修饰符；sema 强制「类默认 final」：继承非 open/abstract/sealed 类报错，重写非 open 方法报错 |
| `abstract` | ✅ | 抽象类/抽象方法；sema：abstract 方法不得有方法体、只能出现在 abstract 类中；abstract 方法天然可被重写 |
| `init` | ✅ | `init { ... }` 初始化块 + 兼容 Aura 既有惯例 `init(params) { ... }` 构造函数；sema 检查块内表达式 |
| `companion` | ✅ | `companion object [Name] { 成员 }`；伴生成员并入类成员表、方法注册为 `Class.method`；多于一个伴生对象报错 |
| `constructor` | ✅ | 次构造函数 `[可见性] constructor(...) [: super(...)/this(...)] { ... }`；委托调用记录在 AST |
| `internal` | ✅ | 上下文关键字接通 `Visibility::Internal`（AST 既有变体）；仅在后随声明起始 token 时生效 |
| `operator` | ✅ | 函数修饰符（`FnModifier::Operator`），运算符重载分派属后续 codegen 工作 |
| `infix` | ✅ | 函数修饰符（`FnModifier::Infix`），中缀调用语法属后续 parser 工作 |
| `tailrec` | ✅ | 函数修饰符；sema 校验函数体必须含自递归调用（否则报错），循环优化属后续 codegen 工作 |
| `reified` | ✅ | 泛型类型参数标记 `fun <reified T>`，`TypeParam.reified` 记录 |
| `vararg` | ✅ | 升级为正式上下文关键字（要求后随参数名，消除同名标识符歧义） |
| `out` | ✅ | 保留既有 Ident 匹配（`class Box<out E>`），与 `in` 型变体一致 |
| `noinline` | ✅ | 参数级修饰符，`Param.is_noinline` 记录 |
| `crossinline` | ✅ | 参数级修饰符，`Param.is_crossinline` 记录 |
| `expect` / `actual` | ✅ | 类与函数修饰符，记录到 AST（单文件模型下 expect/actual 配对检查暂缓） |
| `get` / `set` / `field` | ✅ | 属性访问器：`var x: T get() = ... set(v) { field = ... }`；sema 中 `field` 绑定为底层字段、setter 参数未标注类型时继承属性类型 |
| `typeof` | ⏸ | Kotlin 2.0 特性，暂缓 |
| `file` / `param` / `property` / `setparam` / `dynamic` | ⏸ | 属性委托 / 动态类型系统，暂缓 |

### 设计要点

- **上下文关键字（Kotlin modifier keywords 风格）**：`open`/`abstract`/`internal`/`operator`/`infix`/`tailrec`/`vararg`/`noinline`/`crossinline`/`reified`/`expect`/`actual`/`get`/`set`/`field`/`constructor`/`init`/`companion` 在词法上仍是 `Ident`（不进 `lexer.rs` 的 KEYWORDS 保留字表），仅在特定语法位置被 parser 识别——与 Kotlin 语义一致，这些词仍可用作标识符，保证向后兼容。
- **AST 扩展**：`FnModifier` 新增 8 个变体、`ClassModifier` 新增 4 个；`ClassDecl`/`StructDecl`/`ActorDecl` 新增 `init_blocks`/`constructors`/`companion_objects` 字段；`StructField` 新增 `accessors`；`Param` 新增 `is_noinline`/`is_crossinline`；`TypeParam` 新增 `reified`。
- **sema 增强**：继承开放性检查（非 open 类不可继承）、override-open 合法性检查、abstract 方法校验、tailrec 自递归校验、companion 唯一性校验。
- **存量代码适配**：`examples/` 中 4 处继承示例按 Kotlin 语义补上 `open`/`sealed`（类默认 final 的破坏性变更）。
- **尚未落地（后续工作）**：函数默认参数的 codegen 注入（`f(1)` 调用带默认值参数仍需显式传参，为独立存量缺陷）。
- **测试**：`compiler/tests/sema_tests.rs` 新增 16 个语义测试；`compiler/tests/snapshots.rs` 新增 `snapshot_parser_kotlin_keywords` 快照；`compiler/tests/class_runtime_tests.rs` 13 个运行时集成测试；示例 `examples/classes/test_companion.aura`、`examples/classes/class_runtime.aura`。

### Codegen 落地（2026-09-07 第二批，P-K2）

上述关键字对应的运行时语义已全部落地（此前仅有语法+语义校验）：

| 特性 | 实现 |
|------|------|
| 类方法/字段运行时 | 方法降级为 `Class.method`（含 self 首参）；调用点按接收者静态类型分派（sema 表达式类型 + 继承链 + 唯一候选兜底）；类体内裸字段 → `self.field`、裸方法调用 → `Class.method(self, ...)`（局部变量遮蔽感知） |
| `init` 块 / `constructor` | 合成 `Class.__ctorN`（N=实参数量）；`New` 降级：字段默认值 → 构造函数；init 块随每个构造函数执行；`super(...)`/`this(...)` 委托 |
| `companion` | 伴生方法合成 `Class.name`、字段合成零参读取函数；`Math.max(...)` / `Math.PI` 直达 |
| `operator` | `a + b` → `Class.plus(a, b)`（plus/minus/times/div/mod/eq/ne/lt/gt/le/ge；sema 同步豁免对应类型错误并推断返回类型） |
| `infix` | `a combo b` → `combo(a, b)`（parser Pratt 层；限定同行、右操作数为字面量/标识符/this） |
| `tailrec` | HIR 尾自调用 → 参数重赋值 + `while(true)` 循环（先求值实参到临时变量避免参数覆盖） |
| `get`/`set`/`field` | 合成 `Class.prop.get/set`；读点/写点按接收者类型改写为调用；`field` → `self.<prop>`；setter 参数未标注类型时继承属性类型 |
| `open`/`abstract` 动态分派 | 虚方法表：open/abstract 方法全局槽位编号；emit 为每个类构建 `type_tag → slot → func_idx` vtable（`.auc` v5 序列化，向后兼容 v4 读取）；VM `NewObject` 挂表、`CallMethod` 槽位分派 → **多态生效**（`val a: Animal = Dog(); a.name()` 返回 `"dog"`） |

验证：`examples/classes/class_runtime.aura` 12 项断言全部正确（零诊断）；`cargo test -p compiler` 全绿（仅存量 flaky 的 p10 并发测试除外）。

## 三、缺失的硬关键字

### 🔴 高优先级 — 核心 OOP 能力

#### 1. `open` — 开放继承

- **Kotlin 作用**：标记类/方法可继承（Kotlin 中类和成员默认是 final，必须显式标记 `open` 才能被子类化）
- **Aura 现状**：❌ 无此关键字，词法表、Token 枚举、解析器、AST 均无对应支持
- **影响**：无法定义可继承的类。Aura 当前所有类声明均隐式 final，类继承体系无法建立

```kotlin
// Kotlin 示例
open class Animal {
    open fun speak() { ... }
}

class Dog : Animal() {
    override fun speak() { ... }
}
```

#### 2. `abstract` — 抽象类

- **Kotlin 作用**：声明抽象类，可包含抽象方法（无实现）和具体方法
- **Aura 现状**：❌ 无此关键字
- **影响**：无法定义抽象基类。当前只能通过 `interface` 定义纯接口，缺少"有实现 + 有抽象方法"的中间层

```kotlin
// Kotlin 示例
abstract class Shape {
    abstract fun area(): Double
    fun describe() { println("Shape: area=${area()}") }
}
```

#### 3. `init` — 初始化块

- **Kotlin 作用**：类/结构体中执行构造时初始化逻辑的块，在构造函数执行前运行
- **Aura 现状**：❌ 无此关键字，`ClassDecl` 和 `StructDecl` 均无 `init_blocks` 字段
- **影响**：构造函数逻辑无处安放。当前只能通过构造函数默认参数和字段默认值进行初始化，无法执行复杂的初始化逻辑

```kotlin
// Kotlin 示例
class Person(val name: String) {
    var age: Int = 0

    init {
        println("Person($name) created")
        if (name.isEmpty()) throw IllegalArgumentException()
    }

    init {
        age = 25
    }
}
```

#### 4. `companion` — 伴生对象

- **Kotlin 作用**：类的静态成员容器（伴生对象），可声明静态方法、静态属性、伴随构造器
- **Aura 现状**：❌ 无此关键字
- **影响**：无法实现类级别的静态方法/属性。当前需要将所有"静态"成员提升到顶层作用域

```kotlin
// Kotlin 示例
class Math {
    companion object {
        val PI = 3.14159
        fun max(a: Int, b: Int) = if (a > b) a else b
    }
}
```

#### 5. `constructor` — 显式构造函数

- **Kotlin 作用**：显式声明主构造函数和次构造函数（`constructor` / `secondary constructor`）
- **Aura 现状**：❌ 无此关键字
- **影响**：无法定义自定义构造函数。当前只能通过结构体/类的参数列表隐式生成默认构造函数

```kotlin
// Kotlin 示例
class Person {
    constructor(name: String) { ... }
    constructor(name: String, age: Int) { ... }
}
```

#### 6. `internal` — 内部可见性

- **Kotlin 作用**：模块级可见性，同一模块内可见，外部模块不可见
- **Aura 现状**：⚠️ `ast.rs` 中 `Visibility` 枚举声明了 `Internal` 变体，但 `lexer.rs` 词法表中**没有** `internal` 关键字，解析器也不识别
- **影响**：AST 预留了该可见性级别但完全无法使用。当前只有三级：`public`（默认）、`protected`、`private`

```kotlin
// Kotlin 示例 — Aura 当前无法表达
internal class ImplementationDetail { ... }
```

### 🟡 中优先级 — 函数高级特性

#### 7. `operator` — 运算符重载

- **Kotlin 作用**：标记可重载的运算符函数，支持 `plus`, `minus`, `times`, `div`, `mod`, `eq`, `lt`, `get`, `set`, `invoke` 等
- **Aura 现状**：❌ 无此关键字
- **影响**：无法重载运算符。表达式如 `a + b` 仅支持基本类型

```kotlin
// Kotlin 示例
class Vector(val x: Double, val y: Double) {
    operator fun plus(other: Vector) = Vector(x + other.x, y + other.y)
}
```

#### 8. `infix` — 中缀函数

- **Kotlin 作用**：标记可用作中缀调用的函数，无需圆括号
- **Aura 现状**：❌ 无此关键字
- **影响**：无法使用中缀函数语法（如 `a between b and c`），函数调用必须使用圆括号

```kotlin
// Kotlin 示例
infix fun Int.between(from: Int, until: Int): Boolean = this in from..until
val ok = 3 between 1 and 10
```

#### 9. `tailrec` — 尾递归优化

- **Kotlin 作用**：标记尾递归函数，编译器自动优化为循环（消除栈溢出风险）
- **Aura 现状**：❌ 无此关键字
- **影响**：无法获得编译期尾递归优化，递归深度大时有栈溢出风险

```kotlin
// Kotlin 示例
tailrec fun factorial(n: Int, acc: Long = 1L): Long =
    if (n <= 1) acc else factorial(n - 1, n * acc)
```

#### 10. `reified` — 泛型类型恢复

- **Kotlin 作用**：在泛型函数中标记类型参数为 `reified`，使编译器保留类型信息（Kotlin 泛型擦除的解决方案）
- **Aura 现状**：❌ 无此关键字
- **影响**：无法在泛型上下文中获取实际类型信息，无法实现 `is T`、`as T` 等类型检查

```kotlin
// Kotlin 示例
inline fun <reified T> Any?.isInstanceOf(): Boolean = this is T
```

#### 11. `vararg` — 可变参数

- **Kotlin 作用**：声明可变数量参数的参数（等价于 Java 的 `...`）
- **Aura 现状**：⚠️ 解析器通过 `TokenKind::Ident` + 字面量 `"vararg"` 匹配（parser.rs:383-384），但**未作为正式关键字**定义在词法表中
- **影响**：能用但与标识符命名冲突，开发者可能误用 `vararg` 作为变量名

```kotlin
// Kotlin 示例 — Aura 中需写作 `fun log(vararg msgs: String)`，但 `vararg` 作为标识符可能被误用
fun log(vararg msgs: String) { ... }
```

#### 12. `noinline` — 禁止内联 lambda

- **Kotlin 作用**：与 `inline` 配合使用，标记不应被内联的 lambda 参数（因为 lambda 可能需要逃逸或被存储）
- **Aura 现状**：❌ 无此关键字
- **影响**：配合 `inline` 使用的高级 lambda 语义缺失

```kotlin
// Kotlin 示例
inline fun forEachIndexed(
    list: List<String>,
    noinline callback: (Int, String) -> Unit
) { ... }
```

#### 13. `crossinline` — 跨内联上下文

- **Kotlin 作用**：与 `inline` 配合，允许 lambda 在跳出的上下文中被调用
- **Aura 现状**：❌ 无此关键字
- **影响**：高级 lambda 语义缺失

```kotlin
// Kotlin 示例
inline fun sequence(
    first: () -> String,
    crossinline second: () -> String
) { ... }
```

### 🟢 低优先级 — 高级/多平台特性

#### 14. `expect` — 多平台 expect 声明

- **Kotlin 作用**：Kotlin Multiplatform 中声明跨平台共享的接口，平台特定实现用 `actual` 填充
- **Aura 现状**：❌ 无此关键字
- **影响**：多平台开发需要

```kotlin
// Kotlin 示例
expect class Platform()
actual class Platform { ... } // iOS 实现
actual class Platform { ... } // Android 实现
```

#### 15. `actual` — 多平台 actual 声明

- **Kotlin 作用**：配合 `expect` 使用，提供特定平台的实现
- **Aura 现状**：❌ 无此关键字
- **影响**：同上

#### 16. `typeof` — 类型表达式

- **Kotlin 作用**：Kotlin 2.0 引入，用于运行时类型获取（类似 Java 的 `Class<?>`）
- **Aura 现状**：❌ 无此关键字
- **影响**：反射和动态类型转换场景缺失

```kotlin
// Kotlin 2.0 示例
val type = typeof<String>
val value: String = "hello" as typeof<String>
```

#### 17. `out` — 协变类型参数

- **Kotlin 作用**：标记泛型类型参数为协变（`out T`），表示 `T` 只出现在输出位置
- **Aura 现状**：⚠️ 解析器通过 `TokenKind::Ident` + 字面量 `"out"` 匹配（parser.rs:631-633），但**未作为正式关键字**定义
- **影响**：能用但同上问题，与标识符命名冲突

```kotlin
// Kotlin 示例 — Aura 中需写作 `class Box<out T>`，但 `out` 作为标识符可能被误用
class List<out E> { ... }
```

## 四、缺失的软关键字（属性系统）

Kotlin 的属性系统依赖以下 8 个软关键字。**Aura 当前完全没有属性访问器机制**——只有字段声明（`val`/`var`），无法定义带 getter/setter 的计算属性或委托属性。

| 关键字 | Kotlin 作用 | 示例 |
|--------|------------|------|
| `get` | 属性 getter | `val length: Int get() = elements.size` |
| `set` | 属性 setter | `var count: Int set(v) { field = v; notify() }` |
| `field` | 访问器中引用底层字段 | `var x: Int set(v) { field = v + 1 }` |
| `file` | 文件级属性 | `val File.lines: List<String> get() = readLines()` |
| `param` | 委托参数引用 | `class Foo(param name: String, param age: Int)` |
| `property` | 委托参数引用 | `class Foo(property name: String)` |
| `setparam` | setter 委托参数 | `set(value: Int, setparam newValue: Int)` |
| `dynamic` | 动态分派 | `val dynamicObj: dynamic = ...` |

## 五、优先级排序建议

| 优先级 | 关键字 | 理由 |
|--------|--------|------|
| P0 | `open` | 没有它无法建立类继承体系 |
| P0 | `init` | 没有它构造函数逻辑无处安放 |
| P0 | `internal` | AST 已有预留，补词法即可 |
| P1 | `abstract` | 抽象基类是大型项目必备 |
| P1 | `companion` | 静态成员容器，当前只能放顶层 |
| P1 | `constructor` | 自定义构造函数，当前只有默认构造 |
| P1 | `vararg` | 已有解析支持，升为正式关键字即可 |
| P1 | `out` | 已有解析支持，升为正式关键字即可 |
| P2 | `operator` | 运算符重载提升开发体验 |
| P2 | `infix` | 中缀函数语法 |
| P2 | `tailrec` | 尾递归优化 |
| P2 | `reified` | 泛型类型恢复 |
| P3 | `noinline`, `crossinline` | 高级 lambda 语义 |
| P3 | `get`/`set`/`field` | 属性访问器系统 |
| P4 | `expect`, `actual` | 多平台开发 |
| P4 | `typeof` | Kotlin 2.0 新特性 |
| P4 | `param`, `property`, `setparam`, `file`, `dynamic` | 属性委托系统 |

## 六、附录：Aura 独有的 Kotlin 之外关键字

这些关键字不在 Kotlin 中，是 Aura 的差异化设计：

| 关键字 | 用途 |
|--------|------|
| `struct` | 值类型/结构体（对标 C struct / Kotlin `value class`） |
| `actor` | Actor 模型（对标 Erlang/Scala Akka） |
| `unit` | `Unit` 类型关键字 |
| `comptime` | 编译期求值（对标 Zig `comptime`） |
| `defer` | 延迟释放/清理（对标 Go `defer`） |
| `extern` | FFI 外部声明 |
| `value` | 值类标记（对标 Kotlin `value class`） |
| `await` | 显式 await（Kotlin 用 `suspend` 隐式） |
| `async` | 异步函数 |
| `select` | select 表达式 |
| `box` / `weak` | 显式堆分配/弱引用 |
| `malloc` / `free` / `retain` / `release` | 手动内存管理 |
