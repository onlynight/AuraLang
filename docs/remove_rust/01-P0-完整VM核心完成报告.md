## 5. 已知问题（非 VM 缺陷）

以下问题源于 AOT 后端（Emit.aura），非 VM 核心：

| 问题 | 原因 | 影响 |
|------|------|------|
| 浮点运算返回错误值 | AOT 后端 Float 表示缺陷 | 浮点测试失败 |
| toStr(true) 返回 -1 | AOT 后端 Boolean 表示缺陷 | 布尔转字符串异常 |
| typeof() 返回 0 | AOT 后端 typeof 实现缺陷 | 类型查询不可用 |
| 10/0 不抛出异常 | AOT 后端异常处理缺陷 | 异常测试失败 |

这些问题将在后续阶段（AOT 后端完善）修复。

## 6. 架构变化

### 6.1 旧架构（占位桩）

```
Vm.aura (117 行)
  ├── interpret() → return null (占位)
  └── version() → "0.5.0-phase4-phantom"

VmRunner.aura (900 行)
  ├── String-only 栈
  ├── ~25 个操作码
  └── 无对象/类/集合/闭包/异常/FFI
```

### 6.2 新架构（P0 完成）

```
Vm.aura (~900 行)
  ├── 完整指令分派（100+ 操作码）
  ├── Any 值模型（Int/Float/String/Bool/Null/Object）
  ├── 对象模型（Memory.alloc 堆指针）
  ├── ARC 生命周期管理
  ├── 异常处理（处理器栈）
  ├── 闭包管理
  ├── 协程支持（状态保存/恢复）
  └── 并发原语（线程/Mutex/Channel/Atomic/RwLock/Condvar）

VmOps.aura (~350 行)
  ├── 类型判定与转换
  ├── 算术/比较/逻辑运算
  └── 字节码解析工具

VmCollections.aura (~200 行)
  ├── List 操作（堆分配）
  └── Map 操作（线性查找）

VmRunner.aura (~200 行)
  └── 委托到 Vm（向后兼容接口）
```
