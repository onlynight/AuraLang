## 二、自举流程

```
阶段 1: Rust AOT 后端编译 Main.aura
  cargo build --release -p cli --features llvm
  ./target/release/aura.exe build Main.aura --aot -o aura-compiler-native.exe

阶段 2: 原生载体自举编译
  ./aura-compiler-native.exe Main.aura -o aura-compiler-native2.exe

阶段 3: 行为一致性验证
  aura-compiler-native.exe  test.aura -o native1.exe
  aura-compiler-native2.exe test.aura -o native2.exe
  native1.exe > output1.txt
  native2.exe > output2.txt
  diff output1.txt output2.txt  # 应无差异
```

## 五、验证标准

| 标准 | 判定条件 |
|------|----------|
| 自举编译成功 | `aura-compiler-native2.exe` 生成，大小 > 500KB |
| 行为一致 | `diff output1.txt output2.txt` 无差异 |
| 性能可接受 | 差异 < 20% |
| 可重复 | 连续 3 次自举，输出一致 |
